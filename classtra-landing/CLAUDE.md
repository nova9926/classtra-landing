# Classtra marketing website

## Spec
- The full spec is in LANDING_SPEC.md. Read it before any work and follow it.

## Rules
- LOCAL ONLY: never git push, never deploy, no remote. Commit only when I ask.
- This is a separate project from the Classtra app. Never touch the app.
- List the files you will change and wait for my OK before each big step.
- Free open-source components only: shadcn/ui (via the shadcn MCP) + Magic UI (@magicui registry). No paid templates, no API keys.

## Skills for THIS project (exact list)
Use ONLY these skills here:
- apple-design: all motion, transitions, hover/press feedback, pinned hero, parallax, glass feel
- animation-performance: only when I ask, to check smoothness on mobile
- impeccable: only when I ask (/impeccable critique, /impeccable polish) at the end

Do NOT use these skills in this project, even if they seem relevant:
- taste-skill (design-taste-frontend)
- ui-ux-pro-max
- full-stack dev skill
- ponytail
- graphify

## Priorities if anything conflicts
1. LANDING_SPEC.md (layout, colors, fonts, copy)
2. apple-design (how things move and feel)
3. Your own judgment

- Visual reference: docs/design-reference.html is the approved design (static snapshot).
  Match its look: layout, spacing, glass, colors, fonts.
  Do NOT copy its HTML. Rebuild it properly with React + Tailwind + shadcn + Magic UI.
  If it and LANDING_SPEC.md disagree, LANDING_SPEC.md wins (the spec is newer and includes the animations).
